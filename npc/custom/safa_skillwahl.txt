//  lassen.
//
//  ------------------------------------------------------------
//  WAS HIER PASSIERT
//  ------------------------------------------------------------
//
//  Die Geschenke der Tiers B bis SSS geben einen Schadensbonus
//  auf zwei Fertigkeiten. Bis zum 27.08.2026 stand fest, welche
//  zwei das sind - der Knight bekam Bowling Bash und Pierce, ob
//  er so spielt oder nicht.
//
//  Jetzt waehlt der Spieler sie selbst. Einmal, dann endgueltig,
//  wie das Geschenk selbst.
//
//  Der Threshold Warden bindet das Geschenk. Der Wetzstein
//  daneben schaerft zwei Kanten daran. Beide stehen in Valhalla,
//  beide fragen genau einmal.
//
//  ------------------------------------------------------------
//  WAS WAEHLBAR IST
//  ------------------------------------------------------------
//
//  Alle Angriffsfertigkeiten des Klassenbaums, den das Geschenk
//  meint - einschliesslich der geerbten. Ein Dragon Knight sieht
//  also auch Bash und Bowling Bash, nicht nur seine eigenen.
//
//  Ob der Charakter die Fertigkeit schon gelernt hat, spielt
//  keine Rolle. Gewaehlt wird in Valhalla, also vor der ersten
//  Klasse; eine Liste aus gelernten Fertigkeiten waere dort
//  leer.
//
//  NICHT waehlbar ist alles, was keinen Schaden macht. bSkillAtk
//  wirkt ausschliesslich auf Schadensfertigkeiten, und eine
//  einmalige Wahl auf Heal waere ein Klick ins Leere, den
//  niemand rueckgaengig machen kann.
//
//  ------------------------------------------------------------
//  DIE ZAHLEN
//  ------------------------------------------------------------
//
//    90 Geschenke, 260 Gruppen, 1516 waehlbare Fertigkeiten.
//    Die kuerzeste Auswahl hat 3, die laengste 51.
//
//  ------------------------------------------------------------
//  WIE DIE TABELLE ZU LESEN IST
//  ------------------------------------------------------------
//
//  Flache Arrays plus Versatz und Anzahl, wie in
//  safa_wildlife.txt:
//
//    .g_von[s]     erster Gruppenindex des Geschenks s
//    .g_anz[s]     Anzahl seiner Gruppen
//    .gr_name$[g]  Ueberschrift der Gruppe - die Klassenstufe
//    .gr_von[g]    erster Fertigkeitsindex der Gruppe
//    .gr_anz[g]    Anzahl Fertigkeiten
//    .sk_id[i]     Fertigkeits-Id
//    .sk_id2[i]    zweite Id oder 0 - die _ATK-Schwester, die den
//                  Schaden traegt, wenn die sichtbare Fertigkeit
//                  ihn nicht selbst anrichtet. Ist sie gesetzt,
//                  bekommen BEIDE den Bonus.
//    .sk_name$[i]  Anzeigename
//
//  s ist NICHT die Geschenk-Id, sondern
//  (Tier - 4) * 18 + (Position - 1), also 0 bis 89. Die
//  Umrechnung steht unten in S_Slot.
//
//  Warum die Gruppen: ein select() mit vierzig langen Eintraegen
//  sprengt das Menuepaket zum Client. Die groesste Gruppe hier
//  hat 19 Eintraege.
//
//  ------------------------------------------------------------
//  WER DIESE TABELLE LIEST
//  ------------------------------------------------------------
//
//  Der Threshold Warden in npc/custom/safa_start.txt, ueber
//  getvariableofnpc(..., "#safa_skillwahl").
//
//  Die Wahl gehoert dorthin und nicht zu einem eigenen NPC: die
//  Waechterin schickt nach dem Binden sofort nach Veins
//  (savepoint und warp am Ende ihres Ablaufs). Ein zweiter NPC
//  in Valhalla stuende hinter dieser Tuer und waere fuer einen
//  neuen Charakter unerreichbar.
// ============================================================
